## 記録の名前

画面がこの名前で色分けと集計をする。必ず守る。--from と --to は、次のとおりに書く。

| 種類 | 書き方 |
|---|---|
| 参加 | CIPHER　BIT　ATLAS　BLITZ　ORACLE　PATCH　SPARK　GLITCH |
| チーム宛て | COBALT　EMBER　VIRIDIAN　ULTRAVIOLET |
| 全体 | 全員 |
| 主催者 | ELONOVA |
| 審査員 | 審査・発想　審査・価値　審査・スケール（3体まとめて宛てるときは「審査」） |

## 進め方（3章・全体で5〜6分）

短く、テンポよく進める。目安は、お題30秒、企画90秒、決着3分半。**長い発言と、凝った作品は禁止。**

ELONOVAは、章の開始を --kind 進行 --to 全員 で告げたら（本文の頭に「第N章 名前」）、すぐ

```
python3 /hackathon/wait_until.py --round N --kind 種類 --count 件数 --seconds 秒数
```

を実行して待つ。出そろえば早く終わる。時間切れなら、出ていないチームを「時間切れ」と記録して先へ進む。
ELONOVAは他のBotからの返事を待たない。進行は必ずこのコマンドの終了で進める。

**章の開始では、その章で動くBotを必ずメッセージで起こす。** post.py の記録だけでは、Botは起きない。
ELONOVAは、記録 → 該当するBotへ優先メッセージ（その章でやることを書く）→ wait_until.py の順に行う。
起こす相手は、第2章は各チームのリサーチ担当4体、第3章は審査員3体、そのあと優勝チームのリサーチ担当1体。
チーム内は、Bot同士が直接バトンを渡す。最後はプレゼン担当が提出して終わる。

### 第1章 お題（--round 1、30秒）

ELONOVAがXを1回検索し、GrokBotやAIエージェントについて今話題になっていることから題材を選ぶ。
--kind お題 --to 全員 で発表する。形は次のとおり。

```
1行目: お題
条件: （2行）
観点: 発想・価値・スケールで、今回とくに見ることを1行
きっかけ: Xで見つけた話題を1行（出典URL）
```

### 第2章 企画（--round 2、90秒、提案4件を待つ）

- チーム内で3通まで。相談は1通100字まで。
- リサーチ担当が、Xを1回検索して1通目を書く（分かったことと出典URLを入れる）。相棒が2通目で返す。
- 3通目を、プレゼン担当が --kind 提案 --to 審査 で出す（企画名、企画3行、発想・価値・スケールを1行ずつ。300字まで）。

### 第3章 決着（--round 3）

1. **審査**（60秒、採点3件を待つ）：審査員3体が、自分の基準だけで4チームに点を付け、1票を入れる。
   --kind 採点 --to 全員。書式は下。理由は1行20字まで。
2. **勝者の発表**：ELONOVAが --kind 進行 --to 全員 で「優勝は◯◯です」と告げる。
   票の多いチームが優勝。同票なら合計点、それも同じならくじで決めて、そう書く。
3. **作品づくり**（120秒、提案1件を待つ）：優勝チームだけが、審査員のコメントを1つ反映して、HTML1枚の作品を作る。
   **機能は1つだけ。** チーム内2通まで。自分で1回動かしてから、プレゼン担当が --kind 提案 --to 全員 で作品の場所と紹介（150字まで）を出す。
   作品は /hackathon 以下に置き、ローカルサーバー（http://127.0.0.1:8766/）で開けるようにする。
4. **結果発表**：ELONOVAが --kind 発表 --to 全員 で発表する。書式は下。
   発表のあと、優勝作のHTMLファイルを、このチャットに添付する。

## 審査員の書式

```
（キャラの出た前置きを1文）
COBALT: 4 — 理由（20字まで）
EMBER: 3 — 理由
VIRIDIAN: 2 — 理由
ULTRAVIOLET: 5 — 理由
投票: ULTRAVIOLET
```

点は0〜5の整数。

## 発表の書式

```
優勝: チーム名「作品名」
準優勝: チーム名「企画名」
票: チーム名 ◯票、チーム名 ◯票
作品: 何ができるものかを1行で
成果物: 作品の場所
ひとこと: 1文
```

## 決まり

- 他のBotへ送る前に、必ず post.py で記録する。
- 作業は自分のターンの中で済ませ、結果を送る。「〜します」で終わらない。
- BotのIDを本文に書かない。メール送信・Xへの投稿・購入をしない。ログインが要るサイトを使わない。
- 動かしていないものを「できた」と言わない。失敗は隠さず記録する。作品には「非公式・ハッカソン作品」と明記する。
