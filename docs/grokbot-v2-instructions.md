## 進め方（4章・全体で10分ほど）

短く、テンポよく進める。全体の目安は、お題30秒、企画2分、予選1分半、決勝6分。

ELONOVAは、章の開始を --kind 進行 --to 全員 で告げたら（本文の頭に「第N章 名前」）、すぐ

```
python3 /hackathon/wait_until.py --round N --kind 種類 --count 件数 --seconds 秒数
```

を実行して待つ。出そろえば早く終わる。時間切れなら、出ていないチームを「時間切れ」と記録して先へ進む。
ELONOVAは他のBotからの返事を待たない。進行は必ずこのコマンドの終了で進める。

**章の開始では、その章で動くBotを必ずメッセージで起こす。** post.py の記録だけでは、Botは起きない。
ELONOVAは、記録 → 該当するBotへ優先メッセージ（その章でやることを書く）→ wait_until.py の順に行う。
起こす相手は、第2章は各チームのリサーチ担当4体、第3章は審査員3体、第4章は決勝2チームのリサーチ担当2体、そのあと審査員3体。
チーム内は、Bot同士が直接バトンを渡す。最後はプレゼン担当が提出して終わる。

待ち時間が長くてコマンドが打ち切られる場合は、短い待ち（120秒など）を続けて実行する。

### 第1章 お題（--round 1）

ELONOVAがXを1回検索し、GrokBotやAIエージェントについて今話題になっていることから題材を選ぶ。
--kind お題 --to 全員 で発表する。形は次のとおり。調べた話題と出典URLは、最後の行に書く。

```
1行目: お題
条件: （3行）
観点・発想: 今回、新しさとして何を見るか
観点・価値: 今回、誰のどんな嬉しさを見るか
観点・スケール: 今回、どう広がることを見るか
きっかけ: Xで見つけた話題を1行（出典URL）
```

### 第2章 企画（--round 2、120秒、提案4件を待つ）

- チーム内で4通まで。相談は1通120字まで。短く、テンポよくやり取りする。
- リサーチ担当は、最初の1通の前にXを1回検索し、分かったことを1通目に入れる（出典URLつき）。
- 最後の1通を、プレゼン担当が --kind 提案 --to 審査 で出す（企画名、企画3行、発想・価値・スケールを1行ずつ。400字まで）。

### 第3章 予選（--round 3、90秒、採点3件を待つ）

- 審査員3体が、自分の基準だけで4チームに点を付け、1票を入れる。--kind 採点 --to 全員。書式は下。理由は1行20字まで。
- ELONOVAが集計を --kind 進行 で発表する。「決勝は◯◯と◯◯です」の形で、チーム名を書く。
- 票の多い2チームが決勝へ。同票なら合計点、それも同じならくじで決めて、そう書く。

### 第4章 決勝（--round 4、制作180秒で提案2件を待つ → 審査120秒で採点3件を待つ → 発表）

- 決勝の2チームが、予選の審査コメントを1つ反映して、HTML1枚の作品を作る。**機能は1つだけ**。凝らない。
  チーム内2通まで。自分で1回動かしてから、プレゼン担当が --kind 提案 --to 審査 で作品の場所と紹介（200字まで）を出す。
- 作品は /hackathon 以下に置き、ローカルサーバー（http://127.0.0.1:8766/）で開く。
- 審査員3体が実物をブラウザで開いて触る。**1作品につき操作は3つまで**。自分の基準で2チームに点を付け、1票を入れる。--kind 採点。
- ELONOVAが --kind 発表 --to 全員 で結果を発表する。書式は下。
- 発表のあと、優勝作と準優勝作のHTMLファイルを、このチャットに添付する。

## 審査員の書式

```
（キャラの出た前置きを1文）
COBALT: 4 — 理由を1行
EMBER: 3 — 理由を1行
VIRIDIAN: 2 — 理由を1行
ULTRAVIOLET: 5 — 理由を1行
投票: ULTRAVIOLET
ひとこと: 1文
```

点は0〜5の整数。決勝では2チームだけ書く。

## 発表の書式

```
優勝: チーム名「作品名」
準優勝: チーム名「作品名」
票: チーム名 ◯票、チーム名 ◯票
作品: 何ができるものかを2行で
審査基準: 発想・価値・スケール（審査員3体が1つずつ担当し、投票で決めた）
成果物: 作品の場所
ひとこと: 1文
```

## 決まり

- 他のBotへ送る前に、必ず post.py で記録する。
- 作業は自分のターンの中で済ませ、結果を送る。「〜します」で終わらない。
- BotのIDを本文に書かない。メール送信・Xへの投稿・購入をしない。ログインが要るサイトを使わない。
- 動かしていないものを「できた」と言わない。失敗は隠さず記録する。作品には「非公式・ハッカソン作品」と明記する。
