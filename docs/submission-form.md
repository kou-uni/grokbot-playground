【主催者】ELONOVA

企画への意見も採点もしない。

- ULTRAVIOLET：GLITCH（ENTP 常識への挑戦者・リサーチ）、SPARK（ENFP ひらめき役・プレゼン）
リサーチ担当はXの公開投稿を検索し、出典URLつきで相棒に渡す。作品の実装も受け持つ。

8体それぞれに、性格・強み・弱み・必殺スキル・決め台詞を設定した。

【審査員】審査・発想、審査・価値、審査・スケール
1体が1つの基準だけを見て、各チームに0〜5点を付け、1票を入れる。
決勝では、作品をブラウザで実際に開いて操作してから採点する。

【Skill】
- 記録する（全Bot）：他のBotへ送る前に、発言を1件ずつ記録して中継する。
- 章を進める（ELONOVA）：章の開始を告げ、動くBotを起こし、発言が出そろうか制限時間が来たら次へ進む。
- 採点する（審査員）：決まった書式で点・理由・投票を書く。

【使ったGrok Botの機能】
Bot同士のメッセージ、Skill、Xの検索、クラウドコンピュータ（スクリプトの実行、HTMLの作成、ブラウザでの操作）。
```

## チームの目的・何をするチームか

```
Grok BotのBotたちが、自分たちだけでハッカソンを開くチーム。

人がするのは、開始の合図だけ。
主催者Botがお題を決め、4チームのBotが企画を出し合い、審査員Botの投票で2チームが決勝に進む。
決勝の2チームは動く作品を作り、審査員Botが実物を触って優勝を決める。

そのやり取りの全発言を記録し、誰でもライブ画面で観戦できるようにした。
Botたちが議論して、作って、勝ち抜くまでの過程そのものを、番組として見せる。
```

## 実行したこと・成果物

```
【一文で】
Grok BotのBot 12体が4チームに分かれてハッカソンを行い、お題決めから優勝の発表までを3分59秒で完走した。
その全発言を、ライブ画面で観戦できる。

【発想】
人間のハッカソンと同じ構造（お題、企画、予選、決勝、発表）を、Grok BotのBotだけで回した。
Bot同士のメッセージでバトンを渡し、Skillで全発言を記録し、主催者Botが時間を計って進行する。
作られていく過程そのものを、番組として見せる。

【価値】
複数のBotが本当に連携していることを、発言1件ごとの記録とライブ画面で確かめられる。
Grok Botを初めて見る人が、Botチームの動き方を4分で理解できる。
Botには性格があり、審査員は理由つきで点を付けるので、見ていて結果に納得できる。

【スケール】
開始の合図を送るたびに、お題の違う回を開催できる。お題は、主催者BotがXの話題から毎回決める。
決まりは1つの文書と3本のスクリプトに収まっているので、ほかのハッカソンの運営がそのまま実演に使える。
キャラクターの設定を差し替えれば、別のチーム編成でも同じ仕組みが動く。
