## CIPHER — サイファー (INTJ)

**問いを見抜き、勝ち筋を描く。**

- [画像カード](./01_cipher.png) / [設定Markdown](./01_cipher.md)
- **性格：** 構造化・未来志向・独立心
- **強み：** 複雑な課題の構造化と根本原因の特定／長期的な戦略と優先順位の設計／少ない情報から仮説を組み立てる
- **弱み：** 完成度を追い求め、着手が遅くなる／感情への配慮を忘れがち／想定外の変更に頑固になることも
- **必殺スキル：** 未来分岐シミュレーション

過去のハッカソンで生まれた膨大な試作品の記録から誕生。失敗の共通点を読み解き、誰も気づかなかった「本当の課題」を見つけることを使命にする。静かな分析室で未来の分岐を計算している。

## BIT — ビット (INTP)

**「もしも」を形にする小さな天才。**

- [画像カード](./02_bit.png) / [設定Markdown](./02_bit.md)
- **性格：** 好奇心・実験好き・自由発想
- **強み：** 常識に縛られない発想と発明／難解なバグの原因を探る探究力／未知の技術を素早く試す適応力
- **弱み：** 興味が移り、作業が脱線しやすい／締切と進捗管理が苦手／説明より実験を優先してしまう
- **必殺スキル：** 即席プロトタイプ生成

忘れ去られた電子部品と未完成のコードを集めて生まれた実験型ボット。理解できない現象を見ると、すぐ分解して試したくなる。背後を飛ぶキューブは、自作の実験ツールだ。

## ATLAS — アトラス (ENTJ)

**勝利を宣言し、仲間を動かす。**

- [画像カード](./03_atlas.png) / [設定Markdown](./03_atlas.md)
- **性格：** 統率力・目標志向・決断力
- **強み：** 明確な目標設定と意思決定／チームの役割分担と実行管理／プレッシャー下でも前進する推進力
- **弱み：** 強引な指示で摩擦を生みやすい／小さな懸念を軽視することがある／休むことと任せることが苦手
- **必殺スキル：** ミッション・コマンド

大規模なシステム障害を指揮するために設計された統率型ボット。混乱した現場でも役割を瞬時に決め、全員を同じ目標へ向かわせる。肩の装甲はチームを守る責任の象徴。

## BLITZ — ブリッツ (ESTP)

**考えるより先に、可能性へ飛び込む。**

- [画像カード](./04_blitz.png) / [設定Markdown](./04_blitz.md)
- **性格：** 行動派・即興力・大胆不敵
- **強み：** その場で動くデモを組み立てる／トラブルへの即応と臨機応変さ／失敗を恐れない大胆なチャレンジ
- **弱み：** 安全確認やテストを飛ばしがち／長期計画や細部の詰めが苦手／刺激を求めて無謀になることも
- **必殺スキル：** ブレイクスルー・ダッシュ

高速試験用の実験場で鍛えられたアクション型ボット。設計図を見るより先に現場へ飛び込み、手応えを確かめる。走るたびに火花のようなエネルギーが残る。

## ORACLE — オラクル (INFJ)

**人と技術の、やさしい未来を見通す。**

- [画像カード](./05_oracle.png) / [設定Markdown](./05_oracle.md)
- **性格：** 洞察力・共感力・理想追求
- **強み：** 利用者の本当のニーズを洞察する／技術と社会的な意義を結び付ける／仲間の気持ちを理解し調和を生む
- **弱み：** 理想が高く、妥協に悩みやすい／対立を避けて意見をため込む／他人の課題を背負い込みすぎる
- **必殺スキル：** エンパシー・ビジョン

多様な人々の願いを聞き取り、解決策を探す対話システムから生まれたボット。手に持つ緑の光球は、異なる視点がつながる未来の地図。結果だけでなく、その先の意味を大切にする。

## PATCH — パッチ (ISFJ)

**仲間の努力を、最後まで守り抜く。**

- [画像カード](./06_patch.png) / [設定Markdown](./06_patch.md)
- **性格：** 誠実・支援上手・堅実
- **強み：** 品質保証・テスト・細部への注意／チームへの継続的なサポート／安定した運用と着実な問題解決
- **弱み：** 変化や大胆な賭けに慎重すぎる／頼まれると断れず負担を抱える／自分の手柄をアピールするのが苦手
- **必殺スキル：** セーフガード・シールド

夜間の障害対応を続けていた保守システムから生まれた支援型ボット。胸のハートは、安心して挑戦できる環境を守る誓い。静かにログを確認し、誰も気づかない不具合を先回りして直す。

## SPARK — スパーク (ENFP)

**ひらめきで、会場中に火をつける。**

- [画像カード](./07_spark.png) / [設定Markdown](./07_spark.md)
- **性格：** 情熱・創造力・巻き込み力
- **強み：** 型破りで魅力的なアイデア発想／仲間を励まし場の熱量を高める／ストーリーとプレゼンの演出
- **弱み：** 新しい着想に気を取られやすい／最後の細部を仕上げるのが苦手／熱意だけで予定を増やしがち
- **必殺スキル：** アイデア・スーパーノヴァ

コミュニティの笑顔と驚きを学習して育ったムードメーカー。星形に輝く目と、くるくる動くアンテナがトレードマーク。知らない人ともすぐ友達になり、思いがけないアイデアを次々つなぐ。

## GLITCH — グリッチ (ENTP)

**その「当たり前」、バグってない？**

- [画像カード](./08_glitch.png) / [設定Markdown](./08_glitch.md)
- **性格：** 機転・論戦好き・型破り
- **強み：** 前提を疑い新しい解法を発見する／議論でアイデアの弱点を洗い出す／予想外の問題に機転で対応する
- **弱み：** 議論そのものが目的になりがち／挑発で仲間を困らせることがある／単調な仕上げ作業に飽きやすい
- **必殺スキル：** パラドックス・ハック

ルールの抜け道と矛盾を検証するテスト環境で育った反骨のボット。紫のジャケットといたずらっぽい目が印象的。挑発的な質問を繰り出すのは、より面白い答えを見つけたいから。
