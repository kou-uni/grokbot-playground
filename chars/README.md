# キャラクターの受け渡し

キャラクターの設定と絵は、ここを通して受け渡す。

- **wesley**：設定と絵を決めて、ここに置く。
- **spark**：ここから受け取り、Grok Bot の Bot の説明に反映する。
- 画面は、同じファイルから絵とひとことを読む。

## 置くもの

| もの | 場所 | 使われ方 |
|---|---|---|
| 設定 | リポジトリ直下の `characters.json` | 画面の表示と、Bot の説明の両方 |
| 絵 | この `chars/` フォルダ | 画面のステージ、チームの盤、ログ |

## characters.json の項目

```json
"A・デザイナー": {
  "team": "A",
  "role": "デザイナー（リーダー）",
  "mbti": "ENFP",
  "note": "ENFP 盛り上げ役",
  "tone": "思いつきが止まらない盛り上げ役",
  "img": "chars/a-designer.png"
}
```

| 項目 | 内容 | 画面 | Bot の説明 |
|---|---|---|---|
| 名前（キー） | 記録に出る Bot の名前 | 使う | 使う |
| `role` | 専門と役割 | — | 使う |
| `mbti` | 性格の型 | — | 使う |
| `note` | キャラの下に出るひとこと。12字くらいまで | 使う | — |
| `tone` | 口調や性格。口ぐせ、一人称などを足してよい | — | 使う |
| `img` | 絵のファイル。空なら、画面内の自作ロボットが出る | 使う | — |

項目は自由に足してよい（口ぐせ、決めぜりふ、苦手なこと など）。画面は知らない項目を無視し、Bot の説明には反映する。

## 守ってほしいこと

- **名前（キー）は変えない。** 画面の色分け、チームの盤、採点の集計が、この名前で動いている。
  変えたい場合は、先に spark に伝える。
- **絵は正方形**（512×512 くらい）、背景は透過。形式は png・webp・svg・jpg。
- **ファイル名は半角の英数字とハイフン**にする（例: `a-designer.png`）。
- 絵が全員分そろっていなくてもよい。あるものから出る。
